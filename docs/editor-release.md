Shovey Level Editor is a desktop tool for building and testing garden puzzles.

- Paint floors and walls, then add objects, animals, boulders, lanterns, doors and coloured mechanisms.
- Play your puzzle, keep its winning route, and use Undo, Redo and Reset while editing.
- GLM Modify designs variations checked by the actual puzzle engine. Configure your own GLM provider through environment variables.
- Approval is local in this download; production publishing remains a separately configured developer operation.

This download starts with a fresh puzzle and includes Shovey's own artwork.
Story campaigns, comparison datasets, private media and publishing credentials are excluded.

Extract the Linux x86_64 archive and run `./run.sh`. Python 3, SDL2, Cairo, Pango,
Fontconfig and FreeType are required.

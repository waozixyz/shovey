# Screenshots

These are unaltered captures of standalone Shovey. `hero.png` and `editor.png`
show 0.6.107, with 90 approved Classic levels; the others show 0.6.30. They
were captured at 1280 × 800 on a private Xvfb display using disposable saves,
without touching the running editor or player.

- `hero.png`: Classic level 73 at its starting position.
- `classic.png`: the Classic level chooser, with the screenshot profile unlocked through level 26.
- `editor.png`: story level 9 in the integrated Classic editor, on the Objects tab.
- `chooser.png`: the standalone game chooser.

The Island story campaign is unavailable in this release; Island editing is available.

# Screenshots

These are unaltered captures of standalone Shovey 0.6.30, with 26 approved
Classic levels. They were captured at 1280 × 800 on a private Xvfb display
using disposable saves, without touching the running editor or player.

- `hero.png`: Classic level 26 at its starting position.
- `classic.png`: the Classic level chooser, with the screenshot profile unlocked through level 26.
- `editor.png`: story level 6 in the integrated Classic editor.
- `chooser.png`: the standalone game chooser.

The Island story campaign is unavailable in this release; Island editing is available.

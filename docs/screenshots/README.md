# Screenshots

These are unaltered captures of standalone Shovey 0.6.107, with 90 approved
Classic levels, on a private Xvfb display using disposable saves, without
touching the running editor or player.

- `classic.png`: the Classic level chooser in a 600 × 1000 portrait window, with every level open in the screenshot profile.
- `editor.png`: story level 9 in the integrated Classic editor, on the Objects tab, at 1280 × 800.

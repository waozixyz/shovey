# Screenshots

These are unaltered captures of standalone Shovey on a private Xvfb display,
using disposable saves, without touching the running editor or player.
`hero.png`, `classic.png` and `editor.png` show 0.6.107, with 90 approved
Classic levels; `chooser.png` shows 0.6.30. All are 1280 × 800 except
`classic.png`, which is 1920 × 810 so every level fits.

- `hero.png`: Classic level 73 at its starting position.
- `classic.png`: the Classic level chooser, with all 90 levels open in the screenshot profile.
- `editor.png`: story level 9 in the integrated Classic editor, on the Objects tab.
- `chooser.png`: the standalone game chooser.

The Island story campaign is unavailable in this release; Island editing is available.
